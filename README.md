# Вложения Mail.ru → Excel

Расширение Chrome для сбора вложений, доступных в разделе Mail.ru «Вложения» → «Все». Прокручивает список, собирает данные из каждой порции и создаёт настоящий `.xlsx`, отсортированный по размеру от больших файлов к маленьким.

## Установка

1. Скачайте или клонируйте репозиторий. Если скачали ZIP, распакуйте его в постоянную папку.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите «Режим разработчика» справа вверху.
4. Нажмите «Загрузить распакованное расширение» и выберите папку [extension](extension) с файлом `manifest.json`.
5. Обновите страницу почты. Откройте раздел вложений. Можно также нажать значок расширения → «Открыть все вложения».

Панель «Вложения Mail.ru → Excel» появится справа внизу внутри раздела вложений. Панель можно свернуть, нажав на её заголовок. Расширение работает как в общей оболочке `app.mail.ru`, так и на отдельной странице `cloud.mail.ru/attaches`.

Для обновления замените файлы установленного расширения содержимым новой папки `extension`. На странице `chrome://extensions` нажмите значок перезагрузки на карточке расширения и обновите вкладку почты.

## Первый запуск

1. Очистите поиск и дополнительные фильтры по типам файлов / авторам, если они включены. Выберите вид списка, если сайт предлагает выбор вида.
2. Нажмите «Собрать все с начала». Расширение само переключит вкладку «Все», начнёт с верха списка и покажет число найденных файлов.
3. Держите вкладку открытой и видимой. При переходе на другую вкладку сбор ждёт возвращения. Не меняйте аккаунт, раздел и фильтры во время прохода.
4. Дождитесь состояния «Конец списка достигнут», затем нажмите «Скачать Excel». Сверьте также счётчики пропущенных ссылок и неточных размеров.
5. Для проверки откройте из Excel несколько писем, включая входящее и отправленное. Для открытия ссылок в браузере нужно быть авторизованным в соответствующем ящике.

«Пауза» временно приостанавливает сбор. «Стоп» завершает его с частичным результатом. Excel можно скачать в любой момент: незавершённый файл получает в имени пометку `частично`.

«Дособрать» делает повторный проход с самого начала и объединяет результат по ID вложения. Это позволяет восстановить пропуски после ошибки и не смешивать одинаковые имена у разных файлов. «Собрать все с начала» заменяет предыдущий результат; перед новым сбором скачайте нужный Excel.

## Что находится в Excel

Лист «Вложения»:

- имя файла;
- размер в байтах и МиБ, а также исходный размер на странице;
- имя отправителя / автора, адрес автора;
- тема и дата письма;
- кликабельная ссылка на письмо;
- точность размера, ID вложения, статус ссылки.

Имя берётся из данных автора, которые сама страница Mail.ru использует для карточки и подсказки у аватара. Если имени нет, используется адрес. Текст рядом с конвертом — тема письма, она записывается отдельно. Один файл в двух письмах остаётся двумя строками. Разные вложения с одинаковыми именами также остаются отдельными строками.

Лист «О сборе» содержит начало и окончание, причину остановки, охват и счётчики отсутствующих данных. Лист «Журнал» содержит этапы и диагностику прохода.

## Логика сбора

Расширение читает строки текущего списка и данные React-компонентов этих строк. Для удаления дублей используется `data-id`. Из модели карточки берутся ID письма, папка, имя и адрес автора, тема и точный размер.

Ссылки собираются из ID письма и номера его папки в формате `https://app.mail.ru/mail/ПАПКА/0:ID_ПИСЬМА:ПАПКА/`. Длинные ID хранятся строками, чтобы не потерять цифры.

Расширение двигает список через метод прокрутки компонента Mail.ru. Если метод недоступен или позиция не изменилась, расширение пробует прокрутить элемент страницы. Шаг составляет 65% высоты окна списка, поэтому участки перекрываются. После шага расширение ждёт отрисовки строк или проверяет, что текущие строки уже покрывают новый участок. Панель показывает фактическую позицию в загруженной части списка. На нижней границе расширение ждёт 20 секунд и сбрасывает ожидание, если появляются новые данные или меняется высота. Зависшая прокрутка приводит к остановке с частичным результатом.

Стабильный низ списка — проверка интерфейса, а не сверка с серверным общим количеством. При очень медленной подгрузке или изменении списка во время работы возможны пропуски; повторный проход «Дособрать» помогает их закрыть. Для десятков тысяч вложений проход может занять длительное время.

Если внутренние данные Mail.ru недоступны, остаётся чтение HTML: имя, дата, отображаемый размер, адрес из аватара. Округлённый размер пересчитывается с основанием 1024 и явно помечается оценкой. Папка письма не угадывается: без неё ссылка остаётся пустой. Итоговые счётчики показывают такие строки.

## Журнал и контрольные копии

Журнал фиксирует запуск, настройки, добавление строк и количество повторов, ожидание конца, паузу, продолжение, зависания, ошибки, восстановление и экспорт. Хранятся последние 5000 событий; количество удалённых старых событий указано в отчёте.

Кнопка «Скачать журнал» сохраняет диагностический JSON без названий файлов, авторов, адресов почты и подписанных URL. Этот файл можно прислать для разбора ошибки. Полный Excel содержит персональные данные из почты.

Примерно каждые 5 секунд и при штатной остановке создаётся локальная контрольная копия в хранилище расширения. При обновлении той же вкладки она восстанавливается, если URL страницы явно содержит тот же аккаунт (`email` или `x-email`). Если URL не содержит аккаунт, автоматическое восстановление после обновления отключено, чтобы не смешать разные ящики. Кнопка «Дособрать» работает до обновления в любом случае. После закрытия вкладки её контрольные копии удаляются. Перед закрытием скачайте Excel.

«Очистить» удаляет текущий результат и его контрольную копию. Сохранение не защищает от мгновенного аварийного закрытия до последней контрольной точки. Одновременный сбор в нескольких вкладках хранится раздельно.

## Разрешения и данные

Расширение обрабатывает данные локально. Разрешения `storage` и `unlimitedStorage` нужны для контрольных копий. Разрешение `offscreen` позволяет подготовить локальный файл внутри расширения, а `downloads` передаёт его в загрузки Chrome. Скрипты страницы подключаются только на `cloud.mail.ru`, включая встроенную рамку в оболочке почты.

## Проверки

Все тестовые страницы и данные вымышлены. Для запуска из корня репозитория нужны Node.js 22 или новее, Python 3 и Chrome или Chromium.

```text
node tests/check-core.cjs
python tests/check-xlsx.py
node tests/browser-check.cjs
```

Если браузер установлен по нестандартному пути, укажите его в переменной окружения `CHROME_PATH`. Проверки используют отдельный временный профиль. Тестовые книги появляются в `tests/output/`.

Поддержка охватывает раздел вложений Mail.ru. Работа зависит от его разметки и данных React. При недоступности модели расширение использует данные видимых строк и показывает, каких полей не хватило. Сбор рассчитан на активную вкладку браузера. Для другого почтового сервиса потребуется отдельная адаптация.
